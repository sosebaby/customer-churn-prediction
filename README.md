# Customer Churn Prediction

This project predicts customer churn using a machine learning model built in Python.

## Features
- Exploratory data analysis (EDA)
- Feature engineering
- Model training and evaluation
- Jupyter notebook walkthrough

## Tech Stack
- Python
- Pandas, scikit-learn, Matplotlib
- Jupyter Notebook

## How to Run
1. Open `Customer Churn Prediction.ipynb` in Jupyter Notebook.
2. Run the cells to explore data and see model predictions.
